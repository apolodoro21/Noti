# Noti — PWA

Aplicación web instalable y offline para Android/PC.

## Funciones incluidas
- Navegación Lunes–Viernes y Sábado–Domingo.
- Horario editable por día.
- Notas por día con negrita y checklist.
- Tres tipografías: Sans-serif, Serif y Monospaced.
- Lienzo de dibujo con color, grosor, borrador y limpieza.
- Guardado local en el dispositivo.
- Modo oscuro y diseño responsive.
- PWA con funcionamiento offline mediante Service Worker.

## Instalación gratis en Android
1. Publica esta carpeta en un hosting estático con HTTPS, por ejemplo GitHub Pages.
2. Abre la URL en Chrome en Android.
3. Usa el botón de instalación o el menú de Chrome → "Agregar a pantalla principal".

No necesita base de datos, servidor propio ni cuenta de pago para guardar los datos de la app: se guardan localmente en el dispositivo.
